Adds the first working MDX/React editing engine. CodeMirror edits unsaved buffers; a cancellable browser MDX/esbuild-WASM worker resolves opened TSX modules and pinned React/clsx imports without a runtime Node server. Interactive hooks/events execute only in an opaque-origin, hash-CSP preview. File open/download preserves source, and repeated opens preserve existing memory buffers.

Validation: formatting, lint, strict TypeScript, 3 unit tests, production build and 5 Chromium integration/security tests pass. Also verified development-mode compilation, offline rebuilds, original handoff fixtures, iframe self-navigation denial, and host responsiveness during a bounded infinite-loop probe. Exact logs are in docs/validation; decisions and full acceptance status are in docs/decisions and docs/IMPLEMENTATION_STATUS.md.

This is a draft engineering spike, not a hostile-code shipping sandbox. Native Tauri capability enforcement, Linux WebKitGTK and hard CPU/memory limits remain unrun. Full source-map composition is deferred; TypeScript annotations are supported in imported TSX, not MDX. Spike C remains gated. No custom grammar, AI, marketplace, Git sync or desktop packaging was added. Do not merge automatically.
