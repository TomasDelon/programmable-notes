# Sample fixtures

These are text fixtures for Codex to use when building the MDX runtime and regression tests. They are not compiled or executed by this handoff. `security-attempt.mdx` is intentionally a negative-security test and must not be rendered in the privileged application origin.

An implementer must confirm sample syntax against installed MDX versions and adjust **with tests and a recorded reason** if a fixture is invalid. Do not silently pretend a fixture passed.
