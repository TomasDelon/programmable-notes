## Reproduction

Use the same disposable Ubuntu24.04/WebKitGTK2.52.6 QEMU desktop and software
rendering settings as the preceding evidence. Copy the retained observer to the
acceptance checkout's scripts directory and the controller to an administrator
readable location. Create a fresh fixture with `native-test-setup.mjs`. Start the
controller with its `/tmp/pn-native-...` directory, then run as the ordinary user:

```sh
NATIVE_DISPOSABLE_PROFILE=1 node scripts/native-gutter-debugger.mjs --mixed-eol --quotes --multiline-quotes --source-navigation --visual-budget --same-names --extension-case
```

The controller requires an exact known production ELF hash; review/update that
expectation when intentionally testing another binary. It never selects an
arbitrary same-named process. Existing profiles or personal files are unsuitable.
