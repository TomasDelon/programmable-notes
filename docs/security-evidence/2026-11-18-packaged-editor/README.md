# Packaged Linux editor acceptance

The application was built from `622dfb2` with `npm run native:package` and installed from the resulting optimized Debian package. The packaged binary had no test feature. The [package inspection](inspection.log), [installation hashes](install.log) and [guest versions](environment.log) identify the build and environment. The guest used Ubuntu 24.04, software-rendered Xvfb, delegated cgroup v2 and an explicit administrator opt-in for systemd's namespace setup. The existing security settings stayed enabled.

[Packaged acceptance log](acceptance.log) records a real GTK picker, an inline heading change using X11 keyboard input, undo and redo, and an exact UTF-8/CRLF disk save that preserves heading markers, imports, nested JSX and comments. The test kept a recovery copy through the editor UI, rejected an attempted replacement, cancelled a dirty close, then closed the editor and launched a fresh process. It reopened the saved original, restored the draft into a separate buffer, rejected invalid UTF-8 and confirmed the original disk bytes were unchanged. It deleted only the fixture's recovery copy.

The [native IPC log](ipc.log) records the editor positive control, preview denial for the registered recovery and other privileged commands, effective cgroup limits, a separate network namespace and whole-group Stop. It also records a working WebKit counter and content-policy denials. CPU and memory stress, physical GPU and Wayland were outside this run.

The first native runner attempts failed while combining WebDriver text entry and special keys, and later after Escape left WebDriver unable to parse a script result. See the retained [first failure](failed-webdriver-value.log) and [Escape failure](failed-webdriver-escape.log). The passing runner sends commit and undo/redo keys through the authenticated X11 editor window. Escape is covered in Chromium. The packaged run proves cancellation through the native dirty-close dialog.

The [hosted browser and native jobs](https://github.com/TomasDelon/programmable-notes/actions/runs/44338275308) passed at the packaged source revision. The [browser demo artifact](https://github.com/TomasDelon/programmable-notes/actions/runs/44338275308/artifacts/14442082955) includes the served build, three screenshots and short MP4. The [hosted Debian artifact](https://github.com/TomasDelon/programmable-notes/actions/runs/44338275308/artifacts/14443855895) was built separately by CI and can have a different hash from the locally tested Debian package.

The follow-up adds source-preserving Setext editing and a file-store concurrency regression. It was verified separately from the installed package above. Each competing snapshot writer attempts atomic new-file publication and exactly one winner is recoverable.
