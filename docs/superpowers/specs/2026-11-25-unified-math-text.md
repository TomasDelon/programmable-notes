# Unified document and mathematical text

Approved intent: Preview is one document editing surface. Unfinished dollar syntax is ordinary editable text; closed invalid TeX is raw/red without notifications; valid mathematics reveals its exact dollar-delimited source when the document selection enters and renders when selection leaves. No nested math editor, independent history, math form, button role, or extra Tab stop. Unfinished text has identical geometry whether selected or not. The metadata title is passive text, renamed through the existing explicit command; Markdown headings remain ordinary document nodes.

Keep ProseMirror and KaTeX. Reviewed prosemirror-math provides useful navigation reference but its nested view conflicts with this requirement; Milkdown's tooltip/update button also conflicts. Adopt the established text-plus-presentation approach using ProseMirror child text/contentDOM and inert rendering, preserving the existing source patch authority. No wholesale editor replacement or new dependency is necessary.

Incomplete literal TeX retains safe parsing to prevent braces becoming executable MDX. Source provenance must distinguish decoded document characters from original raw bytes and preserve unchanged escapes, BOM, CRLF, whitespace, JSX and imports. The existing trailing-space encoding must not leak into visible text after math reclassification. Never globally decode source or interpret user HTML. Preserve revision checks, canonical undo/redo, recovery and all runtime privileges.

Acceptance requires real browser typing/selection, no nested math fields, stable incomplete-text layout, formula activation/deactivation, red invalid correction, cross-boundary selection, source fidelity, undo/redo and save/reopen. Existing tests must migrate obsolete form interactions, not skip them. Web deployment requires fresh local check, mandatory CI, repeated three-browser verification and actual Cloudflare candidate/principal-origin acceptance. Native GUI behavior is a separate unverified limit unless actually exercised.
